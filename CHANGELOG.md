# Changelog

## 0.2.0

- Add deterministic AsyncAPI 3.0 to MoonBit project generation.
- Generate schema structs, enums, arrays, optional fields, and local references.
- Generate typed message envelopes and transport-neutral operation traits.
- Generate MQTT, Kafka, AMQP, and custom binding configuration skeletons.
- Add split-file and single-file layouts with collision and reference diagnostics.
- Add a JavaScript-target CLI and generated-project CI checks.

## 0.1.0

- Add the AsyncAPI JSON parser and typed document model.
- Add document, payload, header, and compatibility diagnostics.
- Add operation reports, inventory, schema inspection, and lookup APIs.
